# 캔버스와 프론트 화면 대조

2026-10-14, Brilliant `main`의 최종 화면을 읽고 PNG로 확인한 뒤 Nuxt 실제 렌더링을 순서대로 비교했습니다. 캔버스의 예시 데이터는 앱 데이터로 복사하지 않았습니다.

| 화면 | 확인한 차이와 반영 |
| --- | --- |
| 공통 헤더 | 1120px 폭, 59px 높이, 흰색 테두리와 8px 모서리, 로고·메뉴 간격·활성 표시 |
| 홈 | 지도 우측 상단 소개, 하단 3개 통계 카드, 좌측 확대 버튼. 지도 → 설명 → 시작하기·푸터의 3개 화면 |
| 홈 스크롤 | 작은 휠/세로 스와이프를 한 화면 전환으로 처리. 역방향·PageDown·PageUp·Home·End 지원. 다른 페이지에서는 일반 스크롤 복원. 모션 감소 설정 및 지도 확대 중 이동은 별도 처리 |
| 원두 목록 | 상단 어두운 3D 취향 공간 + 우측 취향 분석, 그 아래 검색·상태별 원두 그룹. 카드 높이와 얇은 향미 바 |
| 브루잉 목록 | 카드의 날짜·원두명·6각 맛 프로필·만족도와 작은 HOT/ICE 표시 |
| 카페 목록 | 카페 필터, 카페명·원두·날짜·만족도·메모 카드 |
| 상세 | 목록을 배경으로 820px 모달, 상단 수정·삭제·닫기, 내부 스크롤, Escape·Tab 동작 |
| 로그인 | 가운데 흰색 패널, 브랜드 영역, 카카오 로그인 버튼 |
| 수동 향미 | 큰 향미 → 계열 → 세부 향미의 동심원 휠, 펼침·선택·선택 해제. 직접 입력 지원 |
| 사진 분석 | 실제 OCR/LLM 진행 상태를 별도 대기 화면에 표시. 직접 입력으로 전환 가능 |
| AI 확인 | 원본 사진 확인, 두 열 정보 폼, 텍스트 향미, 선택 구매 정보로 이동. 첫 단계에서 저장할 때 확인하지 않은 가격·중량 후보 제외 |
| 원두 선택 정보 | 가격·중량 → 구매일·상태, 구매처 선택 카드·지도·메모 |
| 구매처 검색 | 860px 모달, 검색 결과 선택 → 지도 확인 → 적용. 후보 선택만으로 폼을 변경하지 않으며 닫기 시 기존 장소 유지. 이름·주소·링크·좌표 자동 저장 |
| 브루잉 레시피 | 원두량·물량 / 온도·그라인더 / 조절값·분쇄도 / 종료 시간 순서, 푸어링 행 |
| 브루잉 맛 | 만족도 별점, 6각 프로필, 느낌, 직접 입력, 메모. 단계 표시와 버튼 간격 |
| 카페 입력 | 마신 커피 → 마신 카페 → 맛 프로파일 → 느낌. 평점은 마지막 단계, 레시피 입력 없음 |
| 카페 지도 | 지도·방문 카페 패널 비율, 좌측 지도 동작 버튼, 카페 목록 카드 |

데스크톱은 캔버스의 색상·모서리·컨테이너 폭·배치에 맞췄고, 모바일에서는 열 수와 여백을 조정했습니다. 구매처의 외부 카카오 SDK는 테스트 fixture로 선택·좌표·적용을 검증했으며 실제 타일과 실제 계정 로그인은 백엔드의 기존 외부 설정이 필요합니다.

검증:

- SSR production 빌드, Vue/TypeScript 타입 검사, Prettier 검사
- 375 / 768 / 1440px의 주요 페이지 가로 넘침·런타임 오류
- 원두 CRUD, 브루잉 재고 차감, 카페 저장, 향미 선택, AI 결과 폼
- 홈 휠·역방향·키보드·모바일 스와이프 및 일반 스크롤 복원
- 상세 모달의 포커스·Escape 닫기·본문 스크롤 복원
- 구매처 후보를 닫았을 때 적용되지 않음, 변경 취소 시 기존 장소 유지, 적용한 좌표 저장
- AI 결과에서 구매 선택 정보를 거치지 않은 저장은 가격·중량을 저장하지 않음

브라우저 캡처는 [screenshots/canvas-review](screenshots/canvas-review)에 있습니다. `purchase-place-dialog.png`와 `bean-optional-selected.png`의 지도는 실제 외부 지도 연결이 아닌 브라우저 테스트 fixture입니다.

최종 확인 결과: 브라우저 테스트 13개 통과, SSR production 빌드·타입 검사·포맷 검사 통과. 구매처 검색 모달은 Escape/Tab과 닫기 후 포커스 복원, 지도 확대·축소를 제공합니다. 카페 평점은 마지막 느낌 단계에 있습니다.
